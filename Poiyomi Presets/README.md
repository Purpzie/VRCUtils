# Poiyomi Presets
- `Purpzie/Realistic` makes poiyomi look a lot better. It turns off a bunch of limits and allows light to properly affect you.
- `Purpzie/Realistic (Global Mask)` is the same, except it expects these channels in global mask slot 1. Substance can export this with the `Unity HD Metallic Pipeline` format. It's the same layout expected by VRC Standard Lite, so you can use it on mobile too.
  - Red: Metallic
  - Green: Ambient Occlusion
  - Blue: Unused, but you can put anything you want here
  - Alpha: Smoothness
- `Purpzie/Nice Matcap` applies a subtle matcap I personally like a lot.
